# Reading Period

A Yale College exam planner for Fall 2026. Add the courses you are taking, see them on the real final-exam grid, and get a day-by-day plan for reading period. If the load trips the college dean’s postponement rules, the plan can move one exam and draft the email.

Notes about what an exam was actually like feed the plan. Sample notes are labeled as samples. Notes you add stay in this browser.

## Run it

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

## What the grid is based on

Exam groups and the December 15–22 schedule come from the Yale College Programs of Study for Fall 2026. The postponement rules come from Academic Regulations, section H. A dean decides. The app is a planning aid.

Common exam groups (61, 63, 64, 65, 69) are the catalog’s typical assignments for languages, introductory English, introductory economics, physics, and introductory mathematics. A section can differ. Check Yale Course Search for the group on your section.
