# YLearn

A light Yale College planner for Fall 2026. Sign in with a Yale email, then use the tabs.

- Today: what each course still needs on the exam
- Courses: your sections and exam groups
- Semester: Week, Grades, and Calendar
- Finals: Grid, Plan, and the note to your college dean

Numbers are suggestions, not the grade in Yale Hub. Sample notes stay labeled as samples. Scores stay in this browser.

## Run it

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

## What the grid is based on

Exam groups, meeting times, and the December 15–22 schedule come from the Yale College Programs of Study for 2026–2027. The calendar comes from the Yale College calendar. Postponement comes from Academic Regulations, section H. A residential college dean decides. The app is a planning aid.

Common exam groups (61, 63, 64, 65, 69) are the catalog’s typical assignments for languages, introductory English, introductory economics, physics, and introductory mathematics. A section can differ. Check Yale Course Search for the group on your section. The sample load uses those typical groups: an L5 language, a college seminar at the MWF 11:35 time that falls in group 34, Intro English, PHYS 1800, MATH 1150, and ENGL 1014 as a group 0 term essay. Those are sample sections, not a promise about a real roster.
